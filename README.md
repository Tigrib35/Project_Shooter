# Voxel Arena

**Voxel Arena** — многопользовательский шутер от первого лица с элементами строительства, выполненный на чистом JavaScript с использованием CSS 3D-трансформаций. Все игроки соединяются напрямую через WebRTC (PeerJS) без центрального сервера.

## 🎮 Особенности

- Полноценный мультиплеер (до 10 игроков) с автоматическим обнаружением пиров.
- Динамическое разрушение и возведение блоков.
- Система оружия с отдачей, перезарядкой и прицеливанием.
- Пауэр-апы: дополнительный боезапас, восстановление здоровья, джетпак и кирпичи для строительства.
- Таблица лидеров с очками, убийствами и смертями.
- Встроенный чат для общения.
- Звуковое сопровождение (выстрелы, шаги, пауэр-апы) с пространственным позиционированием.

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| **W A S D** | Движение вперёд/влево/назад/вправо |
| **Пробел** | Прыжок (удержание включает джетпак) |
| **Shift** | Приседание |
| **Мышь** | Поворот камеры / прицеливание |
| **ЛКМ** | Стрельба (с отдачей) |
| **ПКМ** | Прицеливание (уменьшает разброс) |
| **E + ЛКМ** | Построить блок (красный кирпич) на прицеленном месте |
| **Tab** | Открыть таблицу лидеров |
| **C** | Открыть чат (ввод сообщения) |

## 🚀 Запуск

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (необязательно, но удобно).
2. Клонируйте репозиторий или скачайте файлы проекта.
3. Запустите локальный HTTP-сервер. Например, с помощью расширения **Live Server** в VS Code:
   - Установите расширение "Live Server".
   - Откройте папку проекта и нажмите `Go Live`.
   - Или используйте любой другой сервер, например, `python -m http.server 8000`.
4. Откройте в браузере адрес, который выдал сервер (обычно `http://localhost:5500` или `http://localhost:8000`).
5. Введите имя игрока и нажмите **Play**. Браузер запросит разрешение на блокировку указателя – согласитесь.
6. Игра автоматически найдёт других игроков в той же сети или через интернет (если STUN-серверы доступны).

> **Примечание:** Для игры по интернету все участники должны быть доступны друг другу (прямые соединения WebRTC). При проблемах с подключением попробуйте использовать общедоступные STUN/TURN-серверы (по умолчанию уже настроены в PeerJS).

## 🛠️ Технологии

- [PeerJS](https://peerjs.com/) – библиотека для P2P-соединений.
- [Howler.js](https://howlerjs.com/) – работа со звуком.
- CSS 3D transforms – отрисовка воксельного мира и игроков без использования WebGL.
- Vanilla JavaScript – весь код написан без внешних фреймворков.

## 🧱 Карта и строительство

- Мир состоит из блоков размером 100×100×100 пикселей.
- Игроки могут разрушать блоки выстрелами (после нескольких попаданий блок исчезает).
- Для строительства нужно собрать кирпичи (пауэр-ап) и, удерживая **E**, кликнуть ЛКМ на месте установки.
- Некоторые участки карты содержат пауэр-апы, которые появляются случайным образом.

## 🏆 Система очков

- Убийство врага приносит очки (зависит от части тела, в которую попали).
- Сбор пауэр-апа даёт +10 очков.
- Очки отображаются в таблице лидеров.

## 📝 Примечания для разработчиков

- Для изменения размеров мира или блоков отредактируйте константы `BLOCK_SIZE` и `WORLD_SIZE` в `world.js`.
- Карта загружается из `map.json` – при желании вы можете создать свою карту.
- Для тестирования можно открыть несколько вкладок браузера, чтобы увидеть мультиплеер в действии.
